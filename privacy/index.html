Site record

Privacy

lulzx.com is a personal, read-only website. It has no user accounts, payment flow, comment form, newsletter form, or advertising tracker. You can read the main pages and static notes without submitting personal information. This policy describes the limited data used to deliver the site and the choices available in your browser.

Data stored in your browser

The site uses local storage for two small preferences. It remembers whether you selected the light or dark theme, and it may cache a short public list of GitHub projects so the project cards load quickly. These values stay in your browser. You can remove them at any time by clearing site data for lulzx.com. The site does not use this storage to build an advertising profile or identify you across other websites.

Network requests and logs

The site is delivered through Cloudflare and GitHub Pages. Like most web infrastructure, those services may process request information needed to deliver and protect the site, such as an IP address, requested URL, browser headers, timestamps, and security signals. Their handling of that infrastructure data is governed by their own policies.

Pages may request font files from Google Fonts, application scripts from unpkg, project metadata from the public GitHub API, and images hosted on GitHub or this domain. Those providers receive the network information required to answer the request. The static trust pages and machine-readable files do not require the Vue application to render their text.

Messages you send

If you contact me by email, Telegram, or GitHub, I receive the information you choose to send through that service. Do not send passwords, access tokens, private customer records, or other secrets. I use a message to understand and respond to the request, and I keep it only as long as it remains useful for that conversation or the associated project history.

Questions and changes

Questions or requests about this site can be sent to wiserishabh@gmail.com. If the site's data practices change, this page will be updated to describe the current behavior. Last updated: 22 August 2026.
