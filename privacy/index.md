# lulzx Privacy Policy

lulzx.com is a personal, read-only website. It has no user accounts, payment flow, comment form, newsletter form, or advertising tracker.

## Browser storage

The site remembers the selected light or dark theme and may cache a short public list of GitHub projects in local storage. You can remove both by clearing site data for lulzx.com.

## Network requests

Cloudflare and GitHub Pages deliver the site and may process ordinary request and security logs. Pages may request fonts from Google Fonts, scripts from unpkg, project metadata from the public GitHub API, and images from GitHub or this domain.
