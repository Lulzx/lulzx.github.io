# lulzx projects

Small, focused software projects by lulzx. Most are open source and built to do one job well.

- [cuda-metal](https://github.com/Lulzx/cuda-metal): CUDA compiler and runtime for Apple Silicon: it compiles and runs CUDA kernels on the M-series GPU.
- [zs3](https://github.com/Lulzx/zs3): S3-compatible object storage written in Zig with zero dependencies.
- [WrenJIT](https://github.com/Lulzx/WrenJIT): a tracing JIT compiler for the Wren scripting language.
- [tinypdf](https://github.com/Lulzx/tinypdf): a PDF creation library in less than 400 lines of TypeScript. No dependencies, and the files it writes are real PDFs.
- [zpdf](https://github.com/Lulzx/zpdf): zero-copy PDF text extraction in Zig. Memory-mapped parsing with SIMD acceleration.
- [tinydocx](https://github.com/Lulzx/tinydocx): a minimal DOCX and ODT creation library with no dependencies.
- [tinysoup](https://github.com/Lulzx/tinysoup): a zero-dependency HTML parser for TypeScript with a BeautifulSoup-like API.
- [tinybarcode](https://github.com/Lulzx/tinybarcode): SVG barcode generation in under 1KB gzipped.
- [blaze-bpe](https://github.com/Lulzx/blaze-bpe): a lightweight embeddable tiktoken-compatible BPE tokenizer core in Rust.
- [tiny-kernel](https://github.com/Lulzx/tiny-kernel): fused Metal kernels for LLM inference, written in Zig. No Python, no PyTorch.
- [nn.zig](https://github.com/Lulzx/nn.zig): a neural network in roughly 600 lines of Zig, training with GEMM batching through Accelerate.
- [barunlm-35m-browser](https://github.com/Lulzx/barunlm-35m-browser): the BarunLM-35M language model converted to ONNX and run entirely client-side with onnxruntime-web.
- [hvm](https://github.com/Lulzx/hvm): a Zig implementation of HVM, the Higher-Order Virtual Machine based on the interaction calculus.
- [sectorc](https://github.com/Lulzx/sectorc): a C compiler built from first principles, on the premise that you should trust no compiler you have not verified.
- [warpx-metal](https://github.com/Lulzx/warpx-metal): WarpX electromagnetic particle-in-cell simulations on the Apple Silicon GPU through an AdaptiveCpp SYCL Metal backend.
- [zeno](https://github.com/Lulzx/zeno): GPU-accelerated batched physics simulation for robotics and reinforcement learning on Apple Silicon.
- [driftmap](https://github.com/Lulzx/driftmap): vortex flow map methods for simulating plasma edge turbulence.
- [encept](https://github.com/Lulzx/encept): perceptual image hashing that uses Apple's hardware H.264 encoder as a learned similarity function.
- [ubrowser](https://github.com/Lulzx/ubrowser): fast and cheap browser automation for Claude Code.
- [copilot](https://github.com/Lulzx/copilot): a CLI copilot tool written in Rust.
- [esp32-cam-web-streamer](https://github.com/Lulzx/esp32-cam-web-streamer): live MJPEG webcam firmware for the AI-Thinker ESP32-CAM, viewable in any browser over WiFi.

Everything else is on [github.com/Lulzx](https://github.com/Lulzx).

There is no site-level API for project data. Follow each repository for source, releases, issues, and project-specific documentation.
